# Employee-Productivity-Study

Intern ID:CITS6257


## 📌 Project Overview
This Tableau dashboard analyzes employee productivity and performance using HR data. It provides interactive visualizations that help understand workforce trends, employee performance, department-wise productivity, and key HR metrics for better decision-making.

---

## 🎯 Objectives
- Analyze employee productivity across departments.
- Evaluate employee performance metrics.
- Identify workforce trends and patterns.
- Compare productivity by job roles and departments.
- Support data-driven HR decisions.

---

## 🛠️ Tools Used
- Tableau
- Microsoft Excel (Dataset)

---

## 📈 Dashboard Features
- Employee Productivity Overview
- Department-wise Performance Analysis
- Job Role Distribution
- Employee Performance Metrics
- Interactive Filters
- KPI Cards and Visual Insights

---

## 📊 Key Insights
- Identified high-performing departments.
- Compared employee productivity across different job roles.
- Analyzed workforce distribution.
- Highlighted performance trends to support HR planning.
